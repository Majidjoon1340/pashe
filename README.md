# وزوز: حمله پشه‌ها

نمونه‌ی اولیه‌ی یک بازی واقعیت افزوده‌ی تحت وب برای گوشی. پشه‌ها توی محیط واقعی (خونه، محل کار، حیاط) قایم شدن و بازیکن باید راه بره و با دوربین گوشی پیداشون کنه. وقتی نزدیکشون بشی بهت حمله می‌کنن و باید قبل از نیش زدن با لمس کشته بشن.

روی گوشی‌های اندرویدی که از WebXR/ARCore پشتیبانی می‌کنن (کروم)، راه رفتن دقیق دنبال می‌شه. روی بقیه (مثل آیفون) قدم‌ها با سنسور حرکت شمرده می‌شن. روی کامپیوتر: کشیدن ماوس برای نگاه کردن و W/A/S/D برای راه رفتن.

## اجرا
فقط کافیه `index.html` روی HTTPS باز بشه (دوربین و سنسورها بدون HTTPS کار نمی‌کنن)، مثلاً با GitHub Pages.
روی کامپیوتر هم با کشیدن ماوس یا کلیدهای جهت می‌شه اطراف رو نگاه کرد.

## امکانات
- دو حالت بازی: «حمله به کاربر» و «پرواز آزاد» (هیچ‌کس حمله نمی‌کنه، همه دائم در حال پروازن و باید قبل از تموم شدن وقت زده بشن)
- تصویر زنده‌ی دوربین و چرخش با سنسور جهت گوشی
- پشه‌هایی که به طرف بازیکن میان، نیش، لرزش گوشی، کم شدن سلامتی و حالت «خارش»
- صدای سه‌بعدی وزوز (با هدفون بهتره)
- پنج نوع مهاجم: معمولی، تیزپرواز، چاق، دوقلوساز، شبح
- انتخاب مهاجم اول بازی: پشه، پرنده، هواپیما، موشک یا ستاره‌ی طلایی (مدل سه‌بعدی، صدا و افکت مخصوص خودش)
- مرحله‌ها با سختی ملایم، رادار برای پیدا کردن پشه‌ها، انتخاب اندازه‌ی فضا (اتاق، خونه، فضای باز)

- `lib/three.module.min.js`: کتابخونه‌ی three.js نسخه‌ی 0.160.0 برای نمایش سه‌بعدی (مجوز MIT در `lib/three.LICENSE`)
