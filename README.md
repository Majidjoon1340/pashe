# وزوز: حمله پشه‌ها

نمونه‌ی اولیه‌ی یک بازی واقعیت افزوده‌ی تحت وب برای گوشی. دوربین پشت گوشی روشن می‌شه، پشه‌ها از همه طرف (۳۶۰ درجه، بالا و پایین هم) به سمت بازیکن پرواز می‌کنن و باید قبل از نیش زدن با لمس کشته بشن.

## اجرا
فقط کافیه `index.html` روی HTTPS باز بشه (دوربین و سنسورها بدون HTTPS کار نمی‌کنن)، مثلاً با GitHub Pages.
روی کامپیوتر هم با کشیدن ماوس یا کلیدهای جهت می‌شه اطراف رو نگاه کرد.

## امکانات
- تصویر زنده‌ی دوربین و چرخش با سنسور جهت گوشی
- پشه‌هایی که به طرف بازیکن میان، نیش، لرزش گوشی، کم شدن سلامتی و حالت «خارش»
- صدای سه‌بعدی وزوز (با هدفون بهتره)
- پنج نوع پشه: معمولی، تیزپرواز، چاق، دوقلوساز، شبح
- موج‌های پشت سر هم، زنجیره‌ی امتیاز، فلش راهنما برای پشه‌های خارج از دید
